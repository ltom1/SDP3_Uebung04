\section{Anforderungsdefinition (Systemspezifikation)}

Es soll eine Software zur Verwaltung von \textit{Graphic Objects} in Bildern erstellt werden. Diese \textit{Bilder} sollen im Format SVG mit einem zugehörigen Namen gespeichert werden.
Ein \textit{Bild} kann mehrfach die \textit{Graphic Objects} Rechteck und Kreis enthalten, wobei diese Objekte durch verschiedene Eigenschaften wie die Position oder den spezifischen Größen der Dimensionierung beschrieben werden.
Des Weiteren soll jedes \textit{Graphic Object} in einem gewissen 'Stil' dargestellt werden können. Es sollen entweder gefüllte oder nicht gefüllte Rechtecke oder Kreise erstellt werden können.
Allerdings sollte ein \textit{Bild} nur \textit{Graphic Objects} von \textbf{einem} 'Stil' enthalten können. Somit soll die Software auch für spätere Erweiterung von Stilen implementiert werden.
